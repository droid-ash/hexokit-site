The agent plans before it builds

fab-kit scores every assumption the agent made. Four questions per decision: how clear was the signal, how reversible is it, can the agent know this, how many readings are there. The change starts at 5.0 and every weak decision costs points. Under 3.0 the gate closes and the pipeline tells you what to clarify.

$ fab score --check-gate 7ajq
confidence 2.6 / 5.0 · gate 3.0 · blocked
  1 unresolved · run /fab-clarify

$ fab score --check-gate 7ajq
confidence 3.4 / 5.0 · gate 3.0 · pass
