The agent plans before it builds

fab-kit scores every assumption. Four questions per decision: how clear was the signal, how reversible is it, can the agent know this, how many readings are there. The change starts at 5.0 and every weak decision costs points. Under 3.0 the gate closes and the pipeline tells you what to clarify.

How the gate works
$ fab score --check-gate 7ajq
confidence 2.6 / 5.0 · gate 3.0
blocked · 1 unresolved
run /fab-clarify

$ fab score --check-gate 7ajq
confidence 3.4 / 5.0 · gate 3.0
pass

HexoKit is the base. Each tool adds one thing.

Six small CLIs. Drop any one and the rest keep working.

fab-kitA plan before any agent writes code./fab-new
wtThrowaway git worktrees, one per change.wt create
ideaCatch an idea without breaking flow.idea add
tuWhat your AI coding sessions cost.tu --watch
hopJump to any of your repos.hop --all pull
shllInstalls and updates the whole set.shll setup agent
Claude CodeCodexGemini CLICopilot CLIKimi CodeOpenCodeAntigravityEvery harness reports working, waiting or idle. A pane is just as happily a build, a REPL, ssh, htop. HexoKit never wraps the agent.
