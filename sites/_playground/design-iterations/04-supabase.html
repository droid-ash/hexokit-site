fab-kit

A plan before any agent writes code. The agent scores its assumptions: how clear was the signal, how reversible is it, can it know this, how many readings are there. From 5.0 down; under 3.0 the gate closes.

  • Six stages, none skipped
  • Four questions per decision, from 5.0 down
  • Review in a fresh sub-agent
$ fab score --check-gate 7ajq
confidence 2.6 / 5.0 · gate 3.0
blocked — run /fab-clarify

wt

Throwaway git worktrees, one per change. Parallel agents never step on each other.

  • One folder per change
  • Prune the stale ones
$ wt create flaky-tz
../repo.worktrees/flaky-tz
$ wt delete --stale

idea

Catch an idea without breaking flow. A markdown backlog that feeds the next change.

One command gives an agent its own git worktree and tmux window. Repeat the flag for more panes. Pass -N 3 for three workspaces at once. The launcher is whatever agent CLI you point it at.

Read the riff guide →
terminalfab/project/config.yaml
# a worktree, a window, an agent, a dev server
$ rk riff --skill /fab-fff --cmd "just dev"

# three parallel 'ship' preset workspaces
$ rk riff ship -N 3

# the agent reports in: working · waiting · idle
$ shll setup agent

From your phone, and a screen for the agent

Serve the dashboard over Tailscale and open it on your phone. Same sessions, same boards, same panes. A key bar for tab, ctrl and arrows. Switch on rk gui and the agent gets a desktop in a tile beside your terminals. It opens apps, clicks, types and takes screenshots. You watch. Off by default.

What it refuses to be

An agent wrapper. It reads no agent's output and speaks no agent's protocol. When the agent tools change again, this layer stays put.

It isn't — and that is the point
0databases. State is read from tmux and the filesystem.
0SDKs. Plain markdown prompts and a CLI.
0protocols spoken. A pane is just a pane.
0telemetry without a flag. tu is opt-in, for your costs.

Open source from day one

Seven repos under one tap, all MIT. Every plan, backlog and cost report is a file you can cat, grep and git diff. Issues and Discord, no sales call.
