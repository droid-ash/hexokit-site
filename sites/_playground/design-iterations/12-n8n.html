Build plans you can actually follow

fab-kit puts an intake stage in front of every change. The agent scores each assumption: how clear was the signal, how reversible is it, can the agent actually know this, how many readings are there. The change starts at 5.0 and every weak decision costs points. Under 3.0 the gate closes and the pipeline tells you what to clarify.

fab score · 260913-7ajq
$ fab score --check-gate 7ajq
confidence 2.6 / 5.0 · gate 3.0 · blocked
  1 unresolved: auth provider — run /fab-clarify

$ fab score --check-gate 7ajq
confidence 3.4 / 5.0 · gate 3.0 · pass
→ apply may start · 3 worktrees · rk riff -N 3
