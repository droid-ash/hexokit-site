Not another coding agent. A layer above the one you already use. The agent writes the code. HexoKit holds the terminal, the plan, the worktree and the fleet.

Agent-agnostic

A pane is just a pane. HexoKit reads no agent's output and speaks no agent's protocol.

Plain files

Every plan, backlog and cost report is a file you can cat, grep and git diff.

Built for the phone

Touch targets tuned for a thumb. Boards swipe. Push arrives with the tab closed.

Plan first,
then let it build

fab-kit puts an intake stage in front of every change. The agent writes the plan and scores each assumption it made. Below the gate, the pipeline refuses to run and tells you what to clarify. Above it, the agent runs on its own.

How the confidence gate works
Four questions per decisionsignal · reversibility · competence · readingsStarts at 5.0weak decisions cost points, never averaged awayUnder 3.0, the gate closesand /fab-clarify shows what to answer

One agent
runs the rest

rk operator opens a coordinator you talk to. It watches the fleet, starts the next change, unblocks a stuck one, and pings your phone when it needs you. One shortcut and its console slides down over whatever you are looking at. Your pane never moves.

Meet the operator
rk riff -N 3three worktrees, three windows, three agents, one commandBoardspin panes from any machine side by side, the same board on your phoneOne dot per windowworking, waiting, idle, and a red center when review failed

From your phone,
over your own network

Serve the dashboard over Tailscale and open it on your phone. Same sessions, same boards, same panes. A key bar for tab, ctrl and arrows. The agent waiting on you is one tap away, and nothing leaves your tailnet.

Set up HTTPS over Tailscale
$ tailscale serve --bg http://localhost:3000
$ rk notify "review failed on 7ajq" --title fab
→ https://dev-ws.tail1a2b.ts.net

Give the agent
a screen

rk gui on starts a desktop on the host and puts it in a tile beside your terminals. You watch from the browser or your phone. The agent opens apps, clicks, types and takes screenshots. Off by default, and yours to switch off.
