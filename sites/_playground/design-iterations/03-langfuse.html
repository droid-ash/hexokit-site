Plan, build, review — repeat.

fab-kit puts an intake stage in front of every change. The agent writes the plan and scores each assumption. Below the gate, the pipeline refuses to run and tells you what to clarify. Review runs in a fresh sub-agent and loops back up to three times.

$ fab score --check-gate 7ajq
confidence 2.6 / 5.0 · gate 3.0 · blocked
  1 unresolved: auth provider — run /fab-clarify

$ fab score --check-gate 7ajq
confidence 3.4 / 5.0 · gate 3.0 · pass

Four questions per decision. How clear was the signal, how reversible is it, can the agent actually know this, how many readings are there. The change starts at 5.0 and every weak decision costs points. One risky guess stays visible; it is never averaged away.

From your phone, over your own network.

Serve the dashboard over Tailscale and open it on your phone. Same sessions, same boards, same panes. A key bar for tab, ctrl and arrows. Push arrives with the tab closed, and nothing leaves your tailnet.

Three steps

  • enable HTTPS certificates in the Tailscale admin
  • serve the dashboard over your tailnet
  • open the ts.net address on your phone and tap a pane
$ sudo tailscale set --operator=$USER
$ tailscale serve --bg http://localhost:3000
→ https://dev-ws.tail1a2b.ts.net
$ rk notify "review failed on 7ajq" --title fab

Why HexoKit?

It isA remote, phone-first console for your tmux. Agent-agnostic, no database, state derived from tmux and the filesystem. A spawner (rk riff) and a dashboard (rk serve) that compose.
It isn'tAn agent wrapper. It doesn't speak any agent's protocol, parse any agent's output, or care what's in the pane. That is what makes it outlive whichever agent you run.
One command per agentrk riff creates a worktree, opens a tmux window in it and launches your agent. -N 3 spawns three. Failures roll back.
Watch a fleetEvery session and pane in a sidebar. Pin several into a board. Open the same board on your phone.
Keep the agent in checkWith fab-kit, no code until the plan clears the gate. Review in a fresh sub-agent. Learnings written to docs/memory.
Give it a screenrk gui on puts a desktop in a tile. The agent clicks, types and screenshots. Off by default.

Questions

Does HexoKit replace my coding agent?

No. It is a layer above the one you already use. The agent writes code; HexoKit holds the terminal, the plan, the worktree and the fleet.

What does "no database" mean?

State is read from tmux and the filesystem on every request. Nothing to migrate, nothing to sync, nothing to lose.

How does the phone reach my machine?

Serve the dashboard over your tailnet with tailscale serve --bg http://localhost:3000, then open the ts.net address on your phone.

Why does agent state show a dash?

Run shll setup agent once, then start a fresh agent session. Hooks apply to new sessions.

Can the agent really use the desktop?

Yes, when you switch it on. rk gui on starts a private display; agents drive it with rk gui exec, shot, click and type.

Something broke.

Run rk doctor. It checks tmux, wt, the launcher, the port, and prints per-dependency status.
